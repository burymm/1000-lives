# Задача 5 — Энергия игрока: статус, движение и смерть при истощении

> **Статус:** ТЗ готово к реализации (MVP)
> **Связано:** [task4.md](task4.md) · [backlog.md](../doc/backlog.md) · [readme.md](../readme.md)
> **Дизайн-доки:** [doc/resources/energy.md](../doc/resources/energy.md) (энергия = сытость + вода) · [doc/resources/stamina.md](../doc/resources/stamina.md) (стамина — отдельный короткий ресурс) · [doc/attributes/strength.md](../doc/attributes/strength.md) (сила → масса)

## Цель

Добавить игроку **энергию** — истощаемый ресурс жизни. Расход зависит от массы и действий. Восстанавливается едой/водой. При истощении срабатывают **пороги** (нельзя атаковать → нельзя защищаться → нельзя двигаться), при 0 — смерть. Энергия видна во вкладке «Status» меню игрока.

## Масса

- **Масса тела** = `Сила / 10` (кг). Начальная сила = **450** → тело 45 кг.
- **Рука** = 5 % от массы тела (масса предмета, который держишь).
- **Общая масса `m`** = масса тела + вес всего надетого + вес всего в инвентаре.
- Поля `weight` уже есть: `ItemResource.weight` (предметы) и `EquipmentResource.weight` (оружие/щит). Значения — ориентировочные, поправим позже.
- Все параметры могут меняться → масса и пороги **пересчитываются динамически** (снял доспехи → шаг дешевле → порог ниже).

## Расход энергии

Энергия тратится **всегда** (зависит от общей массы `m`) + **за движения/действия**.

### Постоянный расход

- **Стояние:** `m / 1000` в секунду.
- **Отдых** (клавиша **R**, переключатель): `m / 3000` в секунду (стояние ÷ 3).

### Движение (шаг = 1 секунда движения, минимум 1 шаг за полшага — округление вверх)

| Режим | Стоимость | Как определяется |
|---|---|---|
| Ходьба (ровно) | `m/100` в сек | WASD, Y не меняется |
| Ступеньки вверх | `m/100 × 1.5` (+50 %) | не лезет/не прыгает, **Y растёт** |
| Ступеньки вниз | `m/100 × 1.15` (+15 %) | не лезет/не прыгает, **Y падает** |
| Лестница вверх (лезть) | `m/100 × 3` (+200 %) | Area3D `ladder` |
| Лестница вниз | `m/100 × 2` (+100 %) | Area3D `ladder` |
| **Бег** (Shift, отдельное действие) | **+100 %** к стоимости любого движения (ходьба / ступеньки / лестница) | добавляется поверх |

> Ступеньки = гриды: подъём/спуск определяется по изменению Y, если персонаж **не лезет и не прыгает**.

### Одноразовые действия

| Действие | Стоимость |
|---|---|
| **Прыжок** | `m/100 × 6` (600 % шага) |
| **Спрыгнуть / падение вниз** | `m/100 × 2` (200 % шага) |
| **Кувырок** (`dodge_dash`) | `m/100 × 4` (400 % шага) |
| **Взять предмет** | **2 взмаха**: `2 × (рука + вес) / 50` |
| **Выложить / выбросить предмет** | **1 взмах**: `(рука + вес) / 50` |
| **Бросок** (`throw_item`) | как 5 взмахов: `5 × (рука + вес) / 50` |

### Бой

- **Атака (взмах):** масса предмета в руке = `рука (5% тела) + вес оружия`; взмах = `эта масса / 50`. С пустыми руками = `(5% тела) / 50`.
- **Защита (щит):** `(рука + вес щита) / 100` в секунду.

## Отдых (режим, клавиша R — переключатель «отдых / обычный»)

- **MVP:** во время отдыха персонаж **не может драться и ходить**. На экране — **большая надпись «REST»**. Инвентарь открывать можно. Сделать отдых можно и при «не могу двигаться» (есть/выжидание смерти).
- Анимация сидения **отложена**: в риге (`minnyquinn.glb` / `MeleeLib`) нет ни `Sit`, ни `Crouch`/`Squat`. Без анимации — статичная поза или просто надпись.
- Расход: `m / 3000` в сек.

## Восстановление

- **Еда + напитки** (в доке: еда → сытость, медленно/надолго; вода → гидратация, быстро/короче). Пока в игре один **хлеб** (напитки — потом).
- Поля восстанавливающего предмета: **`energy` (сколько всего)** + **`digest_time` (сек усвоения)**. Скорость = `energy / digest_time`. Пример: хлеб 5000 за 5 с = 1000/с.
- **Использование предметов — только через инвентарь** (меню игрока, уже есть вызов `use_item()` в `player_menu.gd`). Возможно позже — «использовать из руки».
- **У каждого хлеба в мире — свои значения**, редактируются из редактора карт (копия ресурса).

## Пороги (динамические, от текущей массы)

- **Не может атаковать:** осталось меньше, чем на **2 взмаха**: `энергия < 2 × (масса_руки + вес_оружия) / 50`.
- **Не может защищаться:** осталось меньше, чем на **5 с** щита: `энергия < 5 × (масса_руки + вес_щита) / 100`.
- **Не может двигаться:** осталось меньше, чем на **5 шагов** при текущем `m`: `энергия < 5 × (m / 100)`. Тяжелее → порог выше. Снял/выбросил лишнее → можешь ходить.
- **Когда ходить нельзя** — всё ещё можно: **отдыхать**, **есть** (открыть инвентарь), **сражаться** (если хватает энергии) и **блокировать**.
- **0 или меньше → смерть** (существующий `death()`).

> **Правка (решение task6):** лимиты ужесточены — **5 шагов / 2 взмаха / 5 с щита**. Энергия работает как скрытый таймер побега: работа в шахте истощает, игрок вынужден искать выход. Меняется только множитель в порогах, формулы прежние.

## Статус («Status» в меню игрока)

- Показать: текущую энергию + **расход в секунду при стоянии**.
- Сейчас вкладка открыта полностью (для разработки); позже видимость — за **ачивками** (отдельная история).

## Стартовое значение

- Энергия изначально **500**. Позже будет считаться от атрибутов (пока начальная сила 450 — просто константа).

## Редактор карт (chest_editor)

- **Решение:** при правке предмета в сундуке — **копия ресурса** (`resource_local_to_scene`), у копии настраиваемые параметры (`energy`, `digest_time`, `weight`). Каждый хлеб в мире хранит свою копию, правки — прямо в редакторе карт.
