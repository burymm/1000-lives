## Общие принципы

- Все атрибуты и ресурсы скрыты — интерфейса нет.
- Игрок читает своё состояние через **поведение и реплики персонажа**.
- Атрибуты сбрасываются смертью. Вечные знания — только через АИ.
- Атрибуты **атрофируются** без использования: не бегаешь → ловкость падает, не читаешь/не колдуешь → интеллект падает. Удача — исключение.
- Падение атрибута ниже **20** → АП *«Атрофия»*: качается, будто уже 500+. 100 таких падений → АИ *«Дистрофик»*: подсказки-предчувствия.
- Пороги: старт **50** · замедление конфликта **200–300** · совершенство **1000** · абсолютный максимум **10 000**.
