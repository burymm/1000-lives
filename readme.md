# Концепт игры: Тысяча жизней (рабочее название)

---

## 1. Общее описание

**Жанр:** RPG / Roguelike / Survival / Immersive Sim

**Цель игры:** Сбежать из рабства, исследовать мир, занять трон (или освободить мир) через множество смертей и перерождений.

**Ключевая идея:**
- Каждая смерть — это урок.
- Игрок учится через опыт, а не через интерфейс.
- Интерфейс открывается только через АИ (Ачивки Игрока).
- Невозможно прокачать всё — выбор определяет твой путь.

---

## 2. Мир и сеттинг

**Старт:**
- Игрок начинает как раб в лагере орков.
- Нужно сбежать, взять оружие и выйти на свободу.

**Конечная цель (вариативна):**
- Занять трон властелина.
- Стать освободителем.
- Выбрать свой путь.

**Локации:**
- Леса, подземелья, города, руины, пещеры.
- Карта отсутствует (или открывается через АИ).

**Враги и расы:**
- Орки, гоблины, тролли, эльфы, люди.
- Коррумпированные существа.
- Каждая раса имеет свои особенности и ветки навыков.
- Полный список существ: [doc/bestiary.md](doc/bestiary.md)

---

## 3. Структура игры

**Жизни:**
- Игрок проживает короткие жизни.
- Смерть — не конец, а инструмент познания.
- Нужно прожить 100+ жизней, чтобы изучить мир и найти свой идеальный билд.

**Начало новой жизни:**
- Можно вселиться в орка (после получения АИ).
- В остальных случаях — старт как раб в лагере орков (или альтернативная точка, если открыта через АИ).

**Экран смерти:**
- Только время, уровень и список названий АП.
- Без пояснений, без статистики.

---

## 4. Прогрессия

### 4.1. АИ (Ачивки Игрока)

**Определение:**
- **Вечные.** Остаются навсегда, между всеми жизнями.
- **Открывают интерфейс и понимание мира.**
- **Не дают силы или бонусов.**
- **Приходят как сюрприз** — игрок не знает, за что получит.
- **Названия появляются как надпись справа снизу** (на несколько секунд).

**Принцип открытия:**
- Суммарное действие за все жизни переваливает порог.
- Пример: съел 1000 предметов → АИ *"Гурман"* → теперь видно чувство голода.
- Пример: сломал ногу 100 раз и не лечил → АИ *"Игнорщик здоровья"* → понимание, что травмы можно лечить.
- Пример: вселился в орка 1000 раз → АИ *"Орк"* → теперь можно выбирать вселение.

**Примеры АИ:**
| АИ | Что открывает | Как получить |
|----|---------------|--------------|
| *"Гурман"* | Индикатор сытости | Съесть 1000 предметов |
| *"Прозрение"* | Понимание коррупции | Умереть в коррупции 10 раз |
| *"Игнорщик здоровья"* | Травмы видны в интерфейсе | Получить 100 травм без лечения |
| *"Орк"* | Свободное вселение в орка | Вселиться в орка 1000 раз |
| *"Мастер навыков"* | Пояснения к АП | Получить 1000 АП суммарно |
| *"Знание урона"* | Видеть минимальный урон оружия | Убить 1000 врагов одним типом оружия |
| *"Дистрофик"* | Подсказки-предчувствия: «мне кажется, скоро я не смогу быстро бегать», «кажется, я скоро ложку не смогу поднести ко рту» | Атрофия 100 раз (атрибут упал ниже 20) |

---

### 4.2. АП (Ачивки Персонажа)

**Определение:**
- **Временные.** Живут до смерти.
- **Дают навыки и способности.**
- **Появляются как надпись справа снизу** (на несколько секунд).
- **Не имеют пояснений** — только название.
- **Эффект скрыт** — игрок понимает его только через поведение персонажа.

**Типы эффектов АП:**
| Тип | Описание | Пример |
|-----|----------|--------|
| **Положительный** | Навык или способность | *"Бегун"* — скорость бега +10% |
| **Отрицательный** | Травма или слабость | *"Сломана нога"* — нельзя бегать и делать сальто |
| **Необычный** | Специфический эффект | *"Берсерк"* — урон при низком здоровье |

**Принцип открытия:**
| Тип АП | Условие | Пример |
|--------|---------|--------|
| **Открытие** | Сделал действие впервые в жизни | Сделал сальто → *"Акробат"* |
| **Прогресс** | Повторил действие N раз | Пробежал 1000 м → *"Спринтер"* |

**Примеры АП:**
| Категория | АП | Эффект (не отображается) |
|-----------|----|---------------------------|
| **Бег** | *"Бегун"* | Скорость бега +10% |
| | *"Марафонец"* | Выносливость +20% |
| | *"Кувыркающийся"* | Уворот в кувырке |
| | *"Лазутчик"* | Бесшумный бег |
| **Лук** | *"Ученик стрельбы"* | Точность +10% |
| | *"Стрелок"* | Скорость перезарядки +15% |
| | *"Снайпер"* | Дальность стрельбы +20% |
| | *"Воздушный стрелок"* | Стрельба в прыжке |
| **Меч** | *"Фехтовальщик"* | Скорость атаки +10% |
| | *"Блокирующий"* | Успешный блок |
| | *"Берсерк"* | Урон при низком здоровье +30% |
| | *"Мастер удара"* | Удар в прыжке |
| **Магия** | *"Ученик огня"* | Заклинание огня |
| | *"Исцеляющий"* | Заклинание лечения |
| **Еда** | *"Любитель мяса"* | Восстановление от мяса +20% |
| | *"Грибник"* | Знание грибов |
| | *"Обжора"* | Медленное снижение голода |
| **Исслед.** | *"Следопыт"* | Видит следы врагов |
| | *"Ночной охотник"* | Лучше видит в темноте |
| **Атрибуты** | *"Атрофия"* | Упавший атрибут (< 20) качается, будто он уже 500+ |

### 4.3. Ветки навыков и специализация

**Открытие ветки:**
- Первое действие в категории открывает ветку.
- Пример: первый выстрел из лука → *"Лучник"* → ветка открыта.

**Развитие ветки:**
- Повторение действий даёт новые АП внутри ветки.
- Чем больше АП в ветке — тем сильнее персонаж в этом направлении.

**Конфликты веток:**
- Нельзя качать всё.
- Прокачал один атрибут → остальные растут медленно (пороги см. в 4.4).
- Ветки блокируют друг друга.
- Пример: высокий уровень в луке → дубина и посох становятся неэффективными.

**Перекачка:**
- Перекачки нет. Выбор ветки — это выбор пути.
- Бросить ветку и качать другую невозможно.

**Универсал = смерть:**
- Средние показатели во всём.
- Нет сильных сторон.
- Враг с высокой специализацией убивает за 2 удара.

### 4.4. Параметры персонажа

Подробно по каждому атрибуту и ресурсу — в [документации](doc/README.md).

**Атрибуты** (скрытые, растут от действий, сбрасываются смертью):

| Атрибут | Растёт от | Производные | Подробно |
|---------|-----------|-------------|----------|
| **Сила** | Удары, тяжёлое оружие, ноша | Здоровье, макс. вес, урон | [doc](doc/attributes/strength.md) |
| **Ловкость** | Бег, прыжки, увороты, стрельба | Скорость, скорость атаки, шанс уворота | [doc](doc/attributes/dexterity.md) |
| **Выносливость** | Расход самой выносливости | Размер стамины | [doc](doc/attributes/endurance.md) |
| **Интеллект** | Магия, чтение, зелья, эксперименты | Мана, сила заклинаний, **ускорение коррупции** | [doc](doc/attributes/intellect.md) |
| **Воля** | Ритуалы, медитация, выживание против коррупции | Сопротивляемость коррупции | [doc](doc/attributes/will.md) |
| **Восприятие** | Разглядывание, слушание, обыск | Зрение и слух, замечание деталей | [doc](doc/attributes/perception.md) |
| **Удача** ⚠ | Риск, критические везения | Влияет на всё случайное | [doc](doc/attributes/luck.md) |

**Ресурсы:**

| Ресурс | Источник | Подробно |
|--------|----------|----------|
| **Здоровье** | Сила | [doc](doc/resources/health.md) |
| **Стамина** | Выносливость. Расход зависит от Ловкости (скорость) и Силы (вес снаряжения) | [doc](doc/resources/stamina.md) |
| **Мана** | Интеллект | [doc](doc/resources/mana.md) |
| **Энергия** (сытость + вода) | Еда и вода | [doc](doc/resources/energy.md) |
| **Коррупция** | Анти-прогрессия (см. раздел 5) | [doc](doc/resources/corruption.md) |

**Пороги:**
| Порог | Значение | Что происходит |
|-------|----------|----------------|
| Старт | 50 | Все атрибуты новичка |
| Замедление конфликта | 200–300 | Остальные атрибуты растут в разы медленнее |
| Совершенство | 1000 | Дальше рост почти останавливается — «полка» билда |
| Абсолютный максимум | 10 000 | Практически недостижим из-за смертности |

**Конфликт:**
- Нельзя качать всё: прокачал один атрибут → остальные растут медленно.
- Перекачки нет — выбор определяет путь навсегда.
- Рост с убывающей отдачей: в начале жизни быстро, к концу — медленно.
- Атрибуты **атрофируются**: не используешь → падают со временем (тяжёлая броня не даёт бегать → ловкость тает; не читаешь и не колдуешь → интеллект тает). Исключение — удача.
- АП не атрофируются: умения не забываются, теряются только смертью.

## 5. Коррупция и проклятое оружие

### 5.1. Проклятое оружие

**Распознавание:**
- По внешнему виду (тёмное, дымящееся, с красными прожилками).
- Без интерфейсных подсказок.

**Особенности:**
- Нельзя снять (до смерти или поломки от износа).
- Каждый удар переносит часть души во врага.
- Ускоряет коррупцию.
- Позволяет вселяться в убитых врагов.

---

### 5.2. Коррупция

Подробно: [doc/resources/corruption.md](doc/resources/corruption.md)

**Стадии:**
| Стадия | Что происходит |
|--------|----------------|
| **< 200** | Мир яркий. Еда и зелья выглядят нормально. Враги — враги. |
| **200+** | Начальные искажения, всё мрачновато. Для орков (старт 200) — уже невесело. |
| **300+** | Все гуманоиды выглядят как орки и гоблины. |
| **500+** | Как в аду. Гуманоиды — демоны, животные — демонические твари. |
| **1000** | Смерть — персонаж полностью переходит под контроль сил зла. |

**Симптомы коррупции (без интерфейса):**
- Цвета тускнеют.
- Еда выглядит как гниль.
- Зелья выглядят как яд.
- Новые места — всегда мрачные.
- Шёпот, звуковые искажения.
- Персонаж иссыхает, лицо темнеет, демонический взгляд.

**Подсказка Гурмана:**
- Еда — детектор правды: «Этот паук отдаёт зайчатиной, странно…» (АИ «Гурман»).

**Коррупция затягивает:**
- Все атрибуты падают, кроме **Интеллекта** — он растёт быстрее.
- Порча толкает к магии → магия ускоряет коррупцию → замкнутый круг. Выход — Воля, ритуал, вселение.

**Лечение коррупции:**
- **Смерть** — полный сброс.
- **Ритуал очищения** (открывается через АИ *"Прозрение"*).
- **Вселение** — сбрасывает часть коррупции.

---

### 5.3. Вселение

**Условие:**
- Убить врага проклятым оружием.
- Автоматически вселиться в тело убитого.

**Особенности:**
- Ты теряешь проклятое оружие (оно остаётся на старом теле).
- Ты начинаешь новую жизнь в теле врага.
- Коррупция частично сбрасывается.

**АИ "Орк":**
- После 1000 вселений в орков.
- Теперь в начале жизни можно выбрать: *"Вселиться в орка?"*.
- Без необходимости проклятого оружия.

## 6. Травмы и лечение

Травмы глаз и режим слепоты: [doc/attributes/perception.md](doc/attributes/perception.md)

**Как получить травму:**
- Неудачное приземление.
- Удар врага по конечности.
- Критическая неудача при действии.

**Примеры травм:**
| Травма | Эффект |
|--------|--------|
| Сломана нога | Нельзя бегать и делать сальто, нет прыжков |
| Ранена рука | Медленная атака, нельзя стрелять |
| Повреждены глаза | Плохая видимость |
| Отравление | Постоянно падает здоровье |

**Травма = АП:**
- Каждая травма — это АП с отрицательным эффектом.
- Травмы живут до смерти (или до лечения).
- Эффекты травм скрыты: игрок понимает их через поведение персонажа.

**Влияние травм на ветки:**
- Травмы автоматически закрывают недоступные ветки (сломана нога → акробатика и лук недоступны), без отдельной таблицы.

**Лечение травм:**
- Можно вылечить полностью (найти ресурсы, целителя).
- Если не лечить — травма остаётся на всю жизнь.
- Некоторые травмы оставляют шрамы (например, кривая нога — медленный бег навсегда).

**АИ "Игнорщик здоровья":**
- Получить 100 травм без лечения.
- Травмы становятся видны в интерфейсе.

## 7. Еда и эксперименты

### 7.1. Общие принципы

Энергия (сытость + вода): [doc/resources/energy.md](doc/resources/energy.md)

- Игрок может есть **любые предметы**.
- Результат непредсказуем.
- Нет подсказок, что можно есть, а что нельзя.
- Игрок учится на своих ошибках.
- Всё, что можно съесть, можно и не есть — выбор игрока.

### 7.2. Еда и зелья
| Предмет | Возможный эффект |
|---------|------------------|
| Обычная еда | Восстановление здоровья |
| Гриб | Лечение, отравление, бафф, яд |
| Зелье | Лечение, урон, бафф, отравление |
| Неизвестный предмет | Любой эффект |

### 7.3. Несъедобные предметы
| Предмет | Попытка съесть |
|---------|----------------|
| Меч | Урон, сломанные зубы, коррупция |
| Камень | Урон, сломанные зубы |
| Книга | Урон, подавился |
| Щит | Невозможно |

### 7.4. Поедание врагов
| Тип врага | Эффект |
|-----------|--------|
| Мёртвый враг | Восстановление здоровья, риск отравления |
| Живой враг | Урон в ответ |
| Коррумпированный враг (шаман) | Временная способность + коррупция |

**АИ "Пожиратель душ":**
- Съесть 10 коррумпированных врагов.
- Понимание, какие враги дают какие способности.

## 8. Технические требования

**Движок:** Godot (рекомендуется) или Unreal Engine 5, Unity.

**Платформы:** PC (в перспективе — консоли).

**Интерфейс:**
- Минималистичный.
- Появляется только через АИ.
- В начале игры — чистый экран.

**Вид:** 3D, от третьего лица (в стиле Souls).

## 9. Принципы дизайна

1. **Обучение через опыт.** Игрок учится, делая ошибки.
2. **Скрытая информация.** Никаких цифр, полосок, подсказок.
3. **Каждая жизнь уникальна.** Травмы, выбор оружия, случайности.
4. **Смерть — это прогресс.** Ты не проигрываешь, ты узнаёшь.
5. **Нет правильного билда.** Есть только твой путь.
6. **Мир реагирует.** Твои действия имеют последствия.
7. **Свобода.** Ты можешь делать всё, что хочешь, но отвечаешь за всё.
8. **Интерфейс — награда.** Ты должен заслужить понимание мира.
