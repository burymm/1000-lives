# Инструкции для агентов

## Git-политика

- **Коммиты и пуши выполняются ТОЛЬКО по явной команде пользователя.**
- Не делай `git commit`, `git push`, `git merge`, `git rebase` или другие изменения истории самостоятельно.
- Если работа завершена и коммит не запрошен — просто сообщи о результате.
- Перед любым коммитом покажи, какие файлы планируется включить (`git status`, `git diff`).
